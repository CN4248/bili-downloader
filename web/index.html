视频重命名规则

可用变量（点击插入到光标处）。模板里写 / 会在下载目录下新建子文件夹，例如 <opus_author>/<opus_title>-<opus_id>-<opus_order>.<ext> → 下载目录/作者名/文件。

动态 / 专栏图文重命名规则

可用变量（点击插入到光标处）。模板里写 / 会在下载目录下新建子文件夹，例如 <opus_author>/<opus_title>-<opus_id>-<opus_order>.<ext> → 下载目录/作者名/文件。

文集重命名规则

文集里的文章用这套规则（普通图文仍用上面的规则）。可用变量（点击插入到光标处）。模板里写 / 会建子文件夹，默认就是「文集标题/文章序号-文章标题/文章id-图片序号」。

默认选择行为

默认：全部分集勾选；合集内其它视频不勾选。

下载哪些文件 可多选；默认下载正常有声视频

全部不勾选时下载正常的有声视频。附加文件（字幕/弹幕/封面/NFO）与所选视频一起下载，文件名沿用“视频重命名规则”（只把扩展名换成 srt/jpg/nfo/m4a）；纯音频与无声视频可以同时勾选，会各下一份文件（.m4a/.mp3 与 -mute.mp4）。放出来没声音时先把「纯音频格式」换成 mp3：老电视、车机、部分媒体库只认 MP3。
